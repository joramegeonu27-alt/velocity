# VÉLOCITY — Refined Compare Edition

This package is the complete previously reconstructed Go project with a quieter Compare-page design.

## What changed
- Compare hero displays the Mercedes–Lexus image at its original 1983 × 793 aspect ratio, 100% width, with no cover/crop, zoom, parallax, CSS scale, or pan.
- Cleaner competitive headline: “LET THE BEST WIN.”, plus a short editorial introduction.
- Simplified colors and visual styling across the Compare page. Bronze accents, matte dark surfaces, smaller radii, subtle transitions.
- Existing vehicle search, three-car selection, VIN research, specification comparisons, charts, saved history and sharing are preserved.
- New responsive hero layout keeps the **full** image visible on mobile, with heading placed above the photograph.

## Run
```bash
go test ./...
go run .
```
Visit http://localhost:8080/compare. Refresh with Ctrl+Shift+R if an older stylesheet is cached.

## Scope and data notes
This ZIP updates the last complete VÉLOCITY copy available in this conversation, and is not a byte-for-byte verification of the newest GitHub commit. The comparison catalogue contains illustrative values; missing values remain unavailable. Live third-party services were not verified end-to-end.
