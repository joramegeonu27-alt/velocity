This is the COMPLETE GO WEBSITE, not merely the small update patch.
It includes main.go, go.mod, all templates, car catalogue data,
static/css, static/js, images and the optimized Lamborghini MP4.

IMPORTANT: KEEP YOUR OLD ~/velocity FOLDER AS A BACKUP.
DO NOT delete it before testing this new build. It contains your .git
folder (GitHub history and remote), and may contain private local .env
settings or newer changes that are not in this download.

INSTALL AS A SAFE SECOND FOLDER (Linux):
1. Download the complete ZIP.
2. In File Manager, rename /home/YOUR_USERNAME/velocity to velocity-backup.
3. Extract the ZIP to your Home folder. It creates ~/velocity.
4. Open ~/velocity in VS Code.
5. In the VS Code terminal run:
     go test ./...
     go run .
6. Open http://localhost:8080/ and http://localhost:8080/cars
7. Check navigation, Search, Marque, Order by, favorites, comparison,
   and the Lamborghini video.

GITHUB IMPORTANT:
This ZIP intentionally DOES NOT contain .git or any secrets.
To keep pushing with your current GitHub connection, the safest
option is to USE your existing Git repository folder instead:
  - Keep the old folder as the working Git repository.
  - Back it up first.
  - Copy the extracted ZIP's files into that existing repo,
    replacing matching files but KEEPING its .git folder.
  - Run go test ./... and git status, then git add/commit/push.

Alternatively you can clone the repo to a new working folder, then
copy the extracted project files over the clone (never replace .git).
